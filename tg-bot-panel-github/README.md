# 🚀 TG Bot Panel

**Мощная Telegram-панель управления для массовых рассылок, парсинга, прогрева аккаунтов и AI-комментариев.**

Полнофункциональный бот-кабинет с подписками, реферальной системой и админ-панелью.

---

## 📸 Возможности

### 👤 Пользовательская панель
- **📁 Сессии** — загрузка .session файлов (по одному или ZIP-пакетом)
- **🗂 Аккаунты** — управление загруженными аккаунтами
- **✉️ Рассылка** — массовая отправка в группы/чаты
- **📤 ЛС-рассылка** — отправка сообщений в личные сообщения
- **📋 Шаблоны** — сохранение и использование шаблонов сообщений
- **⏰ Отложенные** — планирование рассылок на определённое время
- **🗂 Очередь** — отслеживание статуса задач
- **📈 Статистика** — детальная статистика использования
- **🔍 Парсинг** — сбор участников из каналов/групп
- **🤖 Авто-ответы** — автоматические ответы на ключевые слова
- **💎 Подписки** — система тарифов (Trial / Basic / Pro / Admin)
- **👥 Рефералы** — реферальная программа с бонусами
- **📂 Папки целей** — организация списков целей
- **⚙️ Настройки** — управление подписью сообщений

### 👑 Админ-панель
- **📊 Статистика** — общая статистика по боту
- **👥 Пользователи** — управление пользователями (бан/разбан/админ)
- **📨 Глобальная рассылка** — рассылка всем пользователям бота
- **🎫 Инвайт-коды** — генерация кодов для активации подписок
- **⚙️ Настройки** — конфигурация канала, задержек, подписей

### 🛠 Инструменты админа (Telethon)
- **🔥 Автопрогрев** — отправка сообщений в группы для прогрева аккаунтов
- **👻 Теневой инвайт** — тихий инвайт пользователей в группы
- **👁 Масслукинг** — массовый просмотр сообщений в каналах
- **❤️ Масслайкинг** — массовые реакции на посты
- **🎯 Масстаргет** — массовая рассылка по списку целей
- **🧠 AI-комментарии** — генерация комментариев через OpenAI GPT

## ⚡ Быстрый старт

### 1. Клонирование

```bash
git clone https://github.com/targetooov/tg-bot-panel.git
cd tg-bot-panel
```

### 2. Установка зависимостей

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 3. Настройка

```bash
cp .env.example .env
```

Редактируйте `.env`:

| Переменная | Описание |
|---|---|
| `BOT_TOKEN` | Токен бота от @BotFather |
| `API_ID` | API ID из https://my.telegram.org |
| `API_HASH` | API Hash из https://my.telegram.org |
| `SUPER_ADMIN_ID` | Ваш Telegram ID |
| `CHANNEL_ID` | ID канала для Force-Sub (или `0` для отключения) |
| `CHANNEL_URL` | Ссылка на канал |
| `OPENAI_API_KEY` | Ключ OpenAI (для AI-комментариев, опционально) |

### 4. Запуск

```bash
python3 bot.py
```

## 🔑 Ключевые особенности

- **Per-user изоляция** — каждый пользователь работает только со своими аккаунтами и задачами
- **Async на всём** — aiogram 3.x + Telethon + SQLAlchemy async
- **Очередь задач** — асинхронная обработка рассылок
- **Force-Sub** — обязательная подписка на канал
- **Реферальная система** — бонусы за приглашений
- **Пагинация** — удобная навигация по спискам
- **AI-интеграция** — комментарии через OpenAI GPT
